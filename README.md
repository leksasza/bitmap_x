Консольное приложение для работы с BMP-изображениями. Программа предназначена для чтения BMP-файлов, отображения их содержимого в консоли, рисования линии поверх изображения и сохранения результата в новый файл.

**Описание**

Приложение принимает путь к BMP-файлу в качестве аргумента командной строки. Поддерживаются только несжатые изображения с глубиной цвета 24 и 32 бита. После загрузки файл отображается в консоли с использованием двух символов, соответствующих чёрному и белому цветам. Далее пользователь вводит координаты двух точек, между которыми строится линия. Изменённое изображение выводится в консоль и сохраняется в новый BMP-файл.

**Запуск**

Программа запускается из командной строки с указанием входного файла:

./app image.bmp

где app — имя исполняемого файла, а image.bmp — путь к исходному изображению.

**Использование**

После запуска программа ожидает ввод координат линии в формате четырёх чисел: x1, y1, x2, y2. По введённым координатам строится линия, которая отображается поверх исходного изображения. Результат отображается в консоли и записывается в выходной файл.

**Формат входных данных**

Поддерживаются только BMP-файлы без сжатия с глубиной цвета 24 или 32 бита. Другие форматы и варианты кодирования не обрабатываются.

**Детали реализации**

Программа реализует чтение и запись BMP-файлов на уровне бинарных данных без использования сторонних библиотек. Обрабатываются стандартные заголовки файла и изображения. Для построения линии используется алгоритм Брезенхема. При разработке соблюдаются базовые принципы проектирования, такие как минимизация дублирования кода, простота решений и отказ от избыточной функциональности.
